# Intentional differences from the design

`npm run visual` scores and the `visual-reviewer` agent treat these as accepted. Anything not listed here is a gap to fix. Update this file when a difference is fixed or a new one is agreed, and give the screen's lowered threshold in `screens.json` a `why`.

| Screen              | Difference                                                                                                                                      | Why                                                                                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Ready to transcribe | No play button or playback position on the clip                                                                                                 | Playback needs audio in Rust; it comes with the audio module                                                                           |
| Ready to transcribe | Subtitle reads "Check the clip and settings, then start the transcription."                                                                     | "Listen back if you like" would promise the missing playback                                                                           |
| Ready to transcribe | Longer language list than the design's four                                                                                                     | The default Whisper model is multilingual                                                                                              |
| Recording           | Note drops "Transcription starts when you stop."                                                                                                | Stopping leads to the Ready screen, not straight into transcription                                                                    |
| Setup               | No "Change" button for the speech model                                                                                                         | Model switching isn't built                                                                                                            |
| Setup               | Privacy checkbox replaced by a statement                                                                                                        | Saving recordings isn't built (PRD: nothing is stored by default)                                                                      |
| Result              | Info note says "Cleanup removes filler words and repeats…" instead of "Only filler words and repeats were removed…"                             | The app can't guarantee what the model did; the removal marks and the added-words check show it instead                                |
| Result              | The meaning check is a banner on Result that names the added words, with "Use original"                                                         | Shown next to the text it's about, instead of as a separate card                                                                       |
| Errors board        | No meaning-check card; microphone card has only "Try again"; model card offers "Copy command" instead of "Choose another"                       | The meaning check lives on Result; opening system settings and picking another model aren't built                                      |
| All                 | Model name and Ollama address show the real settings (`gemma3:4b`, `127.0.0.1:11434`), not the design's samples (`llama3.2`, `localhost:11434`) | Data, not design                                                                                                                       |
| All                 | The header logo isn't a link                                                                                                                    | One click mustn't throw away work in progress                                                                                          |
| All                 | Outlined buttons are 44px tall everywhere                                                                                                       | The artboards draw some as links, which render 46px (content-box), and others as buttons, which render 44px; the design specifies 44px |
